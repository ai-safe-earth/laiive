## v0.1.0 (2026-08-19)

First live deploy. Everything below this line is generated; this entry is
written by hand because the history before it is a refactor, not a release.

### What shipped

- **Gateway** (Fastify, the only published surface) on Fly at
  `laiive-gateway.fly.dev`: Supabase JWT auth with the role in the token, rate
  limits per role, and proxying to three services that have no public IPs at
  all — reachable only over Fly's private network, behind a shared internal key.
- **Retriever**: one turn is classifier → router → executor → composer over the
  Neo4j graph, with parameterized Cypher templates, `point.distance` with a
  widening radius, vector kNN for vibe asks, a bounding box for neighbourhoods
  that are not cities, and LLM-generated read-only Cypher for the long tail.
  Replies stream as real tokens over SSE.
- **Pusher**: multimodal promoter submission — text, images, audio — through
  extraction, guardrails and a human confirmation, one event per turn.
- **Search**: Tavily sweeps into dry-run reports that only an admin approve can
  write, on a Prefect schedule, with a 202 + poll lifecycle.
- **Frontend**: Vite + React SPA in four languages (en/es/it/ca) with voice
  input and Leaflet maps, talking only to the gateway.
- **`laiive-shared`**: the typed SSE protocol with its TypeScript mirror, and
  the single write path into the graph.
